# Security

Report a vulnerability privately to [support@uthana.com](mailto:support@uthana.com). Please include the package version, the affected tool or file, and a way to reproduce the issue. Do not open a public issue for an undisclosed vulnerability.

Give us a chance to investigate before publishing details. We will acknowledge the report and follow up with a fix or a mitigation.

Do not send API keys, private motion files, or account exports in the report. Describe the impact and redact secrets.
